# KHU VỰC QUẢN TRỊ CHƯƠNG TRÌNH

> **Trạng thái mặc định của nội dung do AI hỗ trợ:** `DRAFT — CHƯA DUYỆT`

- `evidence/`: kho nguồn chứng cứ đã tuyển chọn;

- `knowledge-packs/`: gói kiến thức theo bệnh lý.

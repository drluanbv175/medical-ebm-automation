# Phase 3A User Guide

Mở dashboard Streamlit và vào tab `Chronic Care Shadow Pilot`.

Người dùng chỉ xem dữ liệu synthetic:

- Tổng số synthetic enrollment.
- Queue care coordinator.
- Queue physician review.
- Quality metrics.
- Feature flag status.
- Production block status.

Không nhập dữ liệu thật. Không dùng kết quả để tư vấn người bệnh.

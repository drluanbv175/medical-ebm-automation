# Phase 2D Physician Review Form

This form captures physician review signals for read-only shadow mode. It is not an EMR note and must not contain PII.

## Review Fields

- shadow_case_id:
- reviewer_role:
- pathway_result_status:
- physician_agreement:
- override_reason_category:
- free_text_reason_no_pii:
- recommendation_remains_blocked:
- safety_concern:
- evidence_concern:
- next_review_action:

## Allowed Actions

- agree with blocked/review-only result
- disagree and keep blocked pending evidence review
- request source verification
- request pack revision
- stop pilot if a stop criterion is met

Cần bác sĩ kiểm chứng trước khi áp dụng lâm sàng.

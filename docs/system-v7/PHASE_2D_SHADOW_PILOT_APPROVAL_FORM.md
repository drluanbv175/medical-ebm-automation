# Phase 2D Shadow Pilot Approval Form

This form is a blank review template. It must not be pre-filled by the system as an approval.

## Required Approval Record Fields

- approver_name_or_non_pii_id:
- approver_role:
- approval_scope:
- pack_version:
- approval_date:
- approval_decision:
- conditions_or_limitations:
- signature_or_external_reference:

## Guardrails

- `approval_decision` must be one of: `approved_for_shadow_review`, `rejected`, `needs_revision`.
- Clinical release is not allowed.
- Patient-facing output, prescribing, dose generation, EMR/HIS write, and auto-apply are not allowed.

Current pack approval status remains `pending` until this form is completed by an authorized reviewer.

# Operating Model

EBM OS V7 có 5 lớp:

1. Control plane: `RunPacket`, state machine, policy, audit, approval.
2. Evidence plane: evidence registry, claim registry, citation validation, lifecycle.
3. Safety plane: data sufficiency, red flags, medication safety, contraindications, uncertainty.
4. ResearchOS: protocol, design routing, traceability, SAP, data lock, reproducibility.
5. Interaction plane: dashboard sections, ChatGPT Project bridge, patient education.

Mọi output lâm sàng đi qua quy tắc:

- Không PII.
- Có traceability.
- Có disclaimer.
- Có cổng bác sĩ duyệt.
- Không tự áp dụng.

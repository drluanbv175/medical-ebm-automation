## 4. Monitoring visit report requirements

Each monitoring visit must produce a report containing:
- Date, site, monitor name
- Data reviewed (records, time period)
- Issues found (critical/major/minor)
- Outstanding queries from prior visits
- Confirmed closures
- Recommendations
- Site response (if immediate)
- Signature of monitor

## 5. Monitoring triggers (escalation)

| Finding | Action |
|---------|--------|

| Serious GCP violation | Site may be suspended pending investigation |
| Persistent data quality issues | Increase monitoring frequency |

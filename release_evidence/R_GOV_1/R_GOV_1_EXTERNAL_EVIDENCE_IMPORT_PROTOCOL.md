## Part 1 — Purpose

This protocol defines the steps and safeguards for importing real external governance decisions into the project record. It ensures that:
1. Only genuine external decisions (from ethics committees, hospital authorities, or independent assessors) advance the status of ETH-GOV-01, HOSP-GOV-01, and IQ-GOV-01.
2. No decision status may advance beyond `READY_FOR_EXTERNAL_REVIEW` without human-confirmed external evidence.
3. No AI system, including Claude Code, may self-certify or self-approve any governance decision.

---

## Part 2 — Evidence eligibility criteria

For a document to advance a decision status, it must meet ALL of the following:

| Criterion | Requirement |
|----------|------------|
| Origin | Issued by a recognized external authority (ethics committee, hospital board, qualified independent assessor) |
| Authenticity | PI has physically received the document and can attest to its authenticity |
| Content | Clearly states the decision (approved / rejected / conditional) and its scope |
| Date | Document is dated and within validity period |
| Signature | Signed by the authorized decision-maker (or bears institutional seal) |
| Not self-generated | Document was NOT generated by Claude Code, EBM Copilot, or any AI agent |
| Not self-referential | Document does not reference this pack as authority for the decision |

---

## Part 3 — Import steps

| Step | Actor | Action |
|------|-------|--------|
| 1 | PI | Receives external decision document (physical or digital) |
| 2 | PI | Verifies document authenticity (contact issuing authority if uncertain) |
| 3 | PI | Scans or photographs document; stores securely |
| 4 | PI | Provides the following to Claude Code: (a) document reference (b) issuing authority name (c) decision date (d) decision type (e) conditions if any (f) expiry date if any (g) file path or external link to the document |
| 5 | Claude Code | Records the evidence in `R_GOV_1_EXTERNAL_DECISION_EVIDENCE_INDEX.csv` |
| 6 | Claude Code | Updates status in `R_GOV_1_EXTERNAL_DECISION_REGISTER.csv` from `READY_FOR_EXTERNAL_REVIEW` to `APPROVED_EXTERNALLY` (or other valid state) |
| 7 | Claude Code | Updates the corresponding GO/NO-GO register |
| 8 | PI | Reviews and confirms the update is correct |

---

## Part 4 — What Claude Code CANNOT do

| Prohibited action | Reason |
|----------------|--------|
| Invent an external decision reference | Prohibited — would constitute falsification of governance record |
| Self-issue a qualification, ethics approval, or hospital authorization | Prohibited — only external humans may issue these |
| Mark a decision as APPROVED_EXTERNALLY without human-provided evidence | Prohibited — violates the governance model |
| Advance status based on internal technical evidence alone | Prohibited — technical evidence is necessary but not sufficient |
| Backdate a decision | Prohibited |
| Issue a decision under a fake external authority name | Prohibited |

## Part 5 — Evidence provenance log

For each imported external decision, the following must be recorded:

| Field | Description |
|-------|------------|
| `evidence_id` | Sequential ID (e.g. EXT-ETH-001) |
| `decision_domain` | Ethics / Hospital / Independent Qualification |
| `decision_id` | ETH-GOV-01 / HOSP-GOV-01 / IQ-GOV-01 |
| `issuing_authority` | Name and role of issuing authority |
| `document_title` | Title of the external document |
| `document_date` | Date on the external document |
| `decision` | Approved / Approved with Conditions / Rejected / Revision Requested |
| `conditions` | List of conditions (if any) |
| `expiry_date` | Expiry date of approval (if any) |
| `document_location` | File path or archive reference |
| `pi_confirmed_authenticity` | YES / NO |
| `pi_confirmation_date` | Date PI confirmed |
| `imported_by` | Claude Code + session date |

## Part 6 — Revision and amendment handling

| Scenario | Protocol |
|---------|---------|
| External authority requests revision | Update status to REVISION_REQUESTED; PI prepares response; resubmit |
| Approval expires | Update status to EXPIRED; no study activity until renewed |
| Protocol change requiring re-review | Update status to AMENDMENT_REQUIRED; PI seeks amended approval |
| Approval withdrawn | Update status to REJECTED_EXTERNALLY; all study activity pauses |

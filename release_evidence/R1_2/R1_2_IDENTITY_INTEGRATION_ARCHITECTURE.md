## 1. Architecture overview

```
[Institutional Identity Provider]
    │  (SAML 2.0 / OIDC / LDAP — EXTERNAL — NOT IMPLEMENTED)
    ▼
[Identity Provider Adapter] ← research_project/identity_adapter_contract.py
    │  interface: IdentityProviderAdapterInterface
    │  contract: AuthenticationContextContract
    ▼
[Authentication Context] ← AuthenticationContext dataclass
    │  fields: actor_id, email_hash, roles[], session_id, issued_at, expires_at
    │  invariants: no plaintext PII, no raw credentials
    ▼
[RBAC Policy Engine] ← existing research_project/project_rbac_simulation.py
    │  input: AuthenticationContext.roles + action + object
    │  output: allow / deny + reason_code
    ▼
[Authenticated Audit Ledger] ← future extension of project_audit_attribution.py
    │  fields: event + actor_id + session_id + attribution_mode
    │  constraint: attribution_mode = AUTHENTICATED (when IdP live)
    │             attribution_mode = SYNTHETIC (offline harness)
```

## 3. Authentication context contract

An `AuthenticationContext` is the unit that flows from the IdP adapter to all downstream components. Required fields:

| Field | Type | Invariant |
|-------|------|-----------|
| `actor_id` | str | Non-empty pseudonymous identifier; no raw PII |
| `email_hash` | str | SHA-256 of institutional email; no plaintext email |
| `roles` | list[str] | At least 1 role from approved role registry |
| `session_id` | str | Unique per session; generated by IdP adapter |
| `issued_at_utc` | str | ISO 8601; must be ≤ current time |
| `expires_at_utc` | str | ISO 8601; must be > issued_at_utc |
| `mfa_satisfied` | bool | True only when real MFA has been completed (default: False for SYNTHETIC) |
| `attribution_mode` | str | AUTHENTICATED or SYNTHETIC |
| `disclaimer` | str | Fixed text: "Synthetic identity — not for production use" when mode=SYNTHETIC |

## 5. Session lifecycle design

```
Authentication Request
    ↓
IdP validates credentials + MFA
    ↓
AuthenticationContext issued (session_id, issued_at, expires_at)
    ↓
Session stored in session store (EXTERNAL — not designed here)
    ↓
Each request: validate_session(session_id) → bool
    ↓
Expiry or explicit revoke → revoke_session(session_id) → audit event
```

**Implementation status:** Design only. No session store implemented.

---

## 6. Failure mode design

| Failure | Response |
|---------|---------|
| IdP unavailable | Deny access; log outage event; no fallback authentication |
| Session expired | Deny access; require re-authentication |
| MFA not satisfied | Deny access; prompt MFA completion |
| Unknown actor_id | Deny access; log unknown identity event |
| Revoked session | Deny access; log revocation event |
| RBAC policy deny | Deny access; log SoD/RBAC event with reason_code |

**Design principle:** Fail-secure. No fallback to unauthenticated access.

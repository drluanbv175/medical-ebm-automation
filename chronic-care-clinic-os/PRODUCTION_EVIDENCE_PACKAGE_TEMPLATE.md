# Production Evidence Package Template

This template is a human review checklist for the JSON evidence package generated by
`npm run production:verify -- --init-template <path>`. It is not a real approval until
all artifacts are reviewed and signed by authorized people.

Do not include patient identifiers, PHI, raw datasets, linkage keys, `.env` values,
absolute private paths, or external URLs that expose protected information.

## Required Evidence Domains

- [ ] Repository controls and static gates.
- [ ] Security and privacy controls.
- [ ] Clinical safety controls.
- [ ] UAT with synthetic or de-identified data.
- [ ] Operations, backup, restore and rollback.
- [ ] Incident response and post-deployment monitoring.
- [ ] AI governance, prompt-injection and human-review controls.
- [ ] Legal/compliance review for the signed deployment scope.

## Required Signoff Roles

- [ ] `security_owner`
- [ ] `data_protection_owner`
- [ ] `legal_compliance_owner`
- [ ] `physician_lead`
- [ ] `operations_owner`
- [ ] `ai_governance_owner`
- [ ] `uat_owner`

## Approval Record

- [ ] A final approval record exists.
- [ ] The final approver is authorized for the clinic/site.
- [ ] The final approver is distinct from every signoff signer.
- [ ] The approval scope explicitly includes production go-live review.
- [ ] The approval references only safe, de-identified artifact IDs.

## Go-live Attestation

- [ ] Release ID, change ticket and source commit are recorded.
- [ ] Evidence package SHA-256 matches the reviewed package.
- [ ] Evidence dossier SHA-256 matches the reviewed dossier.
- [ ] Operator and admin approver are distinct.
- [ ] Rollback plan and post-deployment checklist are attached.
